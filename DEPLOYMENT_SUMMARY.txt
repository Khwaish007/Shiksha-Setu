================================================================================
                              HOW IT WORKS
================================================================================

BEFORE (Claude-Only):
  Image Upload → Claude API → Success OR Fail (no backup)

AFTER (Multi-Provider):
  Image Upload → AIProvider → Try Claude
                                 ├─ Success? → Use Claude ✓
                                 ├─ Fail? → Try Gemini
                                 │          ├─ Success? → Use Gemini ✓
                                 │          └─ Fail? → Manual Review ⚠️

KEY BENEFITS:
  ✅ No service downtime if Claude unavailable
  ✅ Automatic failover (no manual intervention)
  ✅ Rate limit protection on both providers
  ✅ Zero frontend changes required
  ✅ Backward compatible
  ✅ Easy to extend to other providers

================================================================================
                           DEPLOYMENT STEPS
================================================================================

1. INSTALL DEPENDENCIES
   $ cd backend && npm install

2. CONFIGURE API KEYS
   $ nano .env  (or edit in your editor)
   
   Add/Update:
   ANTHROPIC_API_KEY=sk-ant-your-existing-key
   GOOGLE_API_KEY=AIzaSy-get-from-https://ai.google.dev/

3. TEST SETUP
   $ npm start
   $ curl http://localhost:3000/api/health
   
   Expected response:
   {
     "status": "ok",
     "aiProviders": {
       "claude": true,      ← Claude available
       "gemini": true,      ← Gemini available
       "primary": "Claude", ← Try Claude first
       "fallback": "Gemini" ← Fallback to Gemini
     }
   }

4. UPLOAD TEST IMAGE
   - Use frontend to upload a test image
   - Watch backend logs for:
     [AIProvider] Attempting Claude...
     [AIProvider] Claude succeeded
   
5. DEPLOY TO PRODUCTION
   - Same steps as above
   - Monitor logs for 24 hours
   - Verify both providers available

================================================================================
                         TROUBLESHOOTING
================================================================================

PROBLEM: "No AI API keys configured"
SOLUTION: Add at least ANTHROPIC_API_KEY or GOOGLE_API_KEY to .env

PROBLEM: Health check shows "claude: false"
SOLUTION: Verify ANTHROPIC_API_KEY in .env (check for spaces/typos)

PROBLEM: Health check shows "gemini: false"
SOLUTION: Get key from https://ai.google.dev/, add to .env

PROBLEM: Fallback not working
SOLUTION: Verify GOOGLE_API_KEY is set and API is enabled in Google Cloud

PROBLEM: High latency
SOLUTION: Normal during fallback (30-45s). Reduce CLAUDE_BATCH_SIZE if frequent.

PROBLEM: Rate limit errors
SOLUTION: Reduce CLAUDE_BATCH_SIZE=1, increase CLAUDE_BATCH_DELAY_MS=2000
